# Setup

1. Commit and push the files in this repository.
2. Open the **Actions** tab and run **Update profile stats** once so the dynamic fields populate immediately.
3. The workflow will refresh the stats daily after that.

The profile artwork is rendered as ASCII text inside `light_mode.svg` and `dark_mode.svg`, so it stays crisp at every size and automatically matches the viewer's color scheme.

`Lines of Code` is calculated from GitHub contributor statistics for public repositories you own where GitHub exposes contributor stats. It is not guaranteed to include every line you have written in repositories owned by other people or organizations.
